# homebrew-tap

Homebrew tap for stackrig.

```sh
brew install tschuba/tap/stackrig
```

`Formula/stackrig.rb` is generated by the release workflow in [tschuba/stackrig](https://github.com/tschuba/stackrig). Do not edit it by hand.

## Token setup (maintainers)

The `tap` job in stackrig's `release.yml` pushes the formula to this repo. It needs a `TAP_TOKEN` secret in the stackrig repo.

1. Create a fine-grained token at <https://github.com/settings/personal-access-tokens/new>.
2. Name it e.g. `stackrig-tap` and set an expiry date.
3. Repository access: *Only select repositories* → `tschuba/homebrew-tap`.
4. Repository permissions: *Contents* → *Read and write* (*Metadata* read is added automatically).
5. Generate the token and copy it.
6. Store it as a secret in stackrig:
   ```sh
   gh secret set TAP_TOKEN -R tschuba/stackrig
   ```
   Paste the token at the prompt.

When the token expires, the `tap` job fails with an auth error. Create a new token and replace the secret.
